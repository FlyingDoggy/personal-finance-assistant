## Settings presentation reuse

The local settings pages directly copy these files from `apps/web/src/finance/settings/` at the same pinned revision:

| Local file | Adaptation |
|---|---|
| `settings-frame.tsx` | Retains the original desktop side menu, mobile menu/page split, FinanceIslands layout and StyleX breakpoints. Replaces Next.js locale/route hooks with a local hash section prop; replaces cloud signed-in member with a local ledger label. |
| `settings-menu.tsx` | Retains original NavList/NavGroup/NavLink and List/ListRow responsive menu rendering, grouping and icon mapping. Replaces localized route strings with local `#settings/...` destinations and Chinese capability labels; removes cloud recovery-email badge. |
| `settings-panel.tsx` | Original component and title/description/action/content structure retained. |
| `settings-sections.ts` | Retains the section/group structure and guard; local list is narrowed to supported accounts, organising, preferences and data. |
| `settings-finance-logo.tsx` | Original mobile logo presentation retained; uses the already copied FinanceLogo and local ledger name. |

`Settings.tsx` connects these presentation files to supported local capabilities. It does not copy upstream cloud credentials, member mutations, remote deletion, bank linking, or financial rules. Unsupported cloud members, FX, bank connection and automation pages are omitted; only currently useful local settings are linked.

## Finance theme

`finance-theme.ts` is copied from `apps/web/src/finance/theme/finance-theme.ts` at the pinned upstream revision without changing its token overrides. It is applied at the document root so portal buttons and selected controls use the original Finance ink accent. The design-system default purple is no longer the app accent. `appearance.ts` adds optional forest/navy overrides and device-local display preferences; these do not alter vendor source or accounting data.

Monthly actual overview adaptation: `analytics-summary.tsx` accepts an optional explicit total action for explicit report composition drill-through; typography and layout remain the upstream presentation, with local responsive amount sizing. The finance visualization plan reuses EIX result contracts separately and does not replace the upstream Finance theme.
