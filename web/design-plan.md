# 生活账本设计计划与自评

对象：希望知道本月生活安排是否够用的个人；首页只回答已设预算、已确认占用与资料缺口。

色彩：纸白 #ffffff、雾蓝 #f3f6f8、深海蓝 #173d51、蓝灰 #647986、墨蓝 #233642、薄荷 #bce1d4；警示使用辅助琥珀色。
字体：标题用系统 PingFang SC / Microsoft YaHei 的较重字重与紧凑字距；正文用系统 sans-serif；金额使用系统 SFMono/monospace 与 tabular-nums，中文标记保留正文体。无远程字体。
布局：侧栏作为安静的账本目录；月份在内容顶部固定可达；移动端使用五栏底部导航。预算年度矩阵可局部滚动，不允许整页横向溢出。

```
目录 | 月份                  导入流水
     | 本月生活安排 / 数据覆盖
     | 日常剩余      | 固定待付 / 年度剩余
     | 最近交易      | 下一步 / 资料缺口
```

标志性元素：本月生活安排是带三个“账页页签”的深蓝账本卡，不以余额/净资产做主视觉；年度预算矩阵保持生活用途行，选择月份像翻到一页。此元素服务日常、固定与年度三类不同含义，避免把它们相加成可任意花的钱。

建造前自评：拒绝通用大数字金融仪表盘与无依据折线，采用真实数据的留白状态；无样例个人金额。克制页签意象，仅在首页主卡使用；流程文字明确解释能做什么，不展示内部技术实现。空值显示待确认/未设置；已知零显示0.00。所有显示数据来自API，金额用BigInt格式，不产生另一份报表算法。
