# 科目目录与使用说明

版本：0.5（科目内容不变）｜日期：2026-10-29｜配套：[主规格](personal-finance-assistant.md)

本目录服务于个人资金与交易管理。以下规则继续替代 v0.1 中房产及耐用品资产化、折旧、预付摊销、强制冲销和月结的旧设计，并以 v0.3 的费用与收入总额口径替代 v0.2 的报销应收默认处理。已有本地加工与工作簿原型，当前已捕获数据已按新口径重算；独立应用与既有账本迁移已完成，MCP和原生持续导入尚未接入。本文只记录通用规则，不包含私人流水。

v0.5 延续 v0.4，保留全部 37 个编码、名称及费用确认规则。本次补充生活预算的展示与执行计量，不因用途分组、年度预留或分期展示增加科目。

## 1. 范围与使用方式

- 默认纳入现金、银行存款及有余额支付账户、投资、公积金；其他有明确债权依据的应收和可退押金按需启用。工作垫付全部留在费用，报销待收只作备忘，不增加应收资产；1004 保留编码但在本模式下停用。信用支付、融资借款、房贷等负债继续管理。
- 房产、汽车及日常耐用品不纳入一期资产，不计折旧。普通商品和订阅在购买时计消费，不做预付摊销。真正未履约预付款、复杂储值权益等尚无适用规则的业务保留待处理，不直接塞入消费或其他应收。
- 正式余额输出名为**账户资产与负债表**。资产减负债称“纳入范围净额”；房产等未纳入而房贷已纳入，净额可能为负，不能称为完整家庭净资产。
- 内部采用资产、负债、系统范围净额、收入、费用五种类型，共 **37 个叶子／系统科目**。当期结余、累计结余是计算行，不是科目，不生成结转凭证。
- 交易分类 UI 显示业务性质和 16 个消费类别；预算首页按生活用途归组，一个用途可关联多个科目或子标签。银行、卡片、支付账户、投资产品、借款合同均为辅助维度；不要求用户每笔面对 37 个科目，也不为每家银行或商户增设科目。
- 4005 名为“其他业务收入”，报销回款和家庭赞助采用不同收入子类型，不新增科目。这里的收入、费用和结余是个人管理口径，不等同企业会计营业收入、成本或净利润；费用总额含工作垫付，不等同纯个人自主消费。
- 用户可直接编辑当前交易；保存变更前后值、操作者、时间、理由和证据链接，按依赖顺序重新生成当前分录与报表。原始证据和历史版本保留；不强制先冲销、不强制月结，旧报表快照不被覆盖。

## 2. 编码、方向与辅助维度

编码固定为四位字符串，首位对应内部类型。表内“借／贷”表示正常余额或发生方向，不禁止退款、损失或范围退出产生反方向记录。负向金额与未知值必须区分；已知绝对余额的信用支付账户出现借方余额时应检查是否属于溢缴款，不能默默与其他账户抵销。期初未知时，本期已知偿债的借方净变动不代表存在溢缴款，绝对负债余额仍应显示未知。

所有已入账业务共同要求：业务 ID、日期、币种、金额、业务性质、证据／可追溯人工确认及版本。以下“必需维度”是在共同字段之外的要求。“可选”指用户可在对应业务入口选择，不提供任意借贷编辑器。人工标签均可留空，不影响已明确业务入账。

## 3. 核心业务映射

下表以“借／贷”说明内部规则；用户仍通过业务入口录入。金额、日期和关联必须来自证据，不能因为模板需要就补造字段。

| 业务 | 最少账务与处理 |
|---|---|
| 普通商品、订阅、服务购买 | 借适用 5xxx，贷 1001 或 2001；商品是家电等耐用品也不转投资或长期资产。真正未履约预付等超出规则的业务留待处理。 |
| 消费明确、类别未知 | 借 5016，贷已确认支付账户／结算应付款；消费和费用口径预算实际照常累计，生活预算按该事实适用规则归集，仅分类待补。 |
| 性质不明的收付 | 已去重且账户、金额、方向确定的收付进入现金表“未解释现金变动”，保留来源及待处理状态，不生成虚构完整凭证；不得借记 1005、贷记 4005 或使用 3001／3002 补平。账面余额及报表完整性继续标缺口，性质补齐仅迁移分类、不新增现金。 |
| 信用支付还款 | 有账户债务及还款证据时借 2001，贷 1001，不重复费用；原消费关系有证据再补，不要求逐笔追溯用途。已证实超还部分借 1003；未说明的金额差异留待核。 |
| 融资分期或房贷还款 | 按证据借 2002／2003 本金及 5012 利息，贷 1001；其他借款使用 2004。缺本息拆分但唯一现金事实明确时，现金表显示“本息待拆付款”，账务继续待处理，不能全计消费或全减本金。 |
| 本人账户互转 | 已确认对端到账时借转入账户 1001、贷转出账户 1001；只证实本人去向但尚未到账时经 1002 中转。仅银行转出及目的账户不能证明对端到账。双方账户维度区分，同科目不同账户不得合并丢失明细。 |
| 退款 | 关联原业务，冲减原 5xxx 或确切的原资产；对应增加 1001、减少 2001 或形成 1003。按已确认退款日计入期间统计；按原消费归因的分析视图另标口径。 |
| 工作垫付与报销回款 | 垫付借适用 5xxx、贷 1001／2001；到账借 1001、贷 4005／报销回款。真实退款按原费用冲回，不能当报销。关联可部分或一对多，待收只记备忘，不生成 1004；拒报仅更新备忘及预测，不重复计费用。 |
| 可退押金／借给他人 | 借 1006／1005、贷 1001；收回反向。扣除、放弃或无法收回须有确认事实后再按用途处理，不自动把所有到期款转消费。 |
| 工资及公积金 | 实收工资可借 1001、贷 4001。已证实来自薪酬、且未被既有收入包含的公积金缴存借 1007、贷 4001；本人从银行另缴则借 1007、贷 1001。完整工资单桥接为可选展开，补资料时修订原业务，禁止收入叠加。 |
| 公积金提取／直接还贷 | 提取至银行借 1001、贷 1007；直接偿还房贷按本息证据借 2003／5012、贷 1007，不伪造银行收支。 |
| 投资买入／卖出 | 买入借 1008、贷 1001，买入费用计成本；卖出按净收入增加 1001、转出对应 1008，差额入 4002，并同步转出已处置部分的 1009／4003。 |
| 投资估值 | 仅当持仓、成本和有日期的有效估值齐备，调整 1009 并对应 4003；估值上涨不产生现金收入。 |
| 借款／家庭赞助及其他赠与 | 借款借 1001、贷 2004；已确认无需偿还的家庭赞助借 1001、贷 4005／家庭赞助，其他赠与另标子类型。家庭赞助不抵费用，未来基准预算默认不依赖。仅有转账摘要不能作此判断。 |
| 期初／范围加入退出 | 经专用入口，以逐项证据建立 1xxx／2xxx 与 3001 或 3002；业务交易、投资损益和未知差异不得混入。 |

**投资证据优先。** 成本未知但有本人持仓快照时，可以展示“已知持仓市值（成本待补）”、快照日和来源，不能将市值当成本或收入。该展示层与正式账面资产小计分开，不与已入账同一持仓重复加总，不生成伪造凭证，也不用于账面勾稽。已实现损益要求处置净收入及对应成本；未实现损益要求剩余成本、持仓和有效估值；个人收益率还要求方法所需的完整现金流、日期和期末价值。缺一项则相应收益保持未知。

1009／4003 可按有证据的持仓、成本和正式净值计算为当前派生余额，或物化为可重算分录；均保留来源、日期与版本，不要求每次净值变化建立不可变凭证链。观察层可提供“已知资产观察小计”，但必须与可重算账本列区分，不能用 3001／3002 填成本缺口。

## 4. 统计口径与正确／错误使用

| 输出／指标 | 口径 | 正确使用 | 错误使用 |
|---|---|---|---|
| 账户资产与负债表 | 按同一截止日和范围汇总启用的 1xxx、2xxx；1008 与 1009 分列，1004 在本模式停用。范围净额＝已纳入账面资产－已纳入账面负债，附缺项及快照展示层。 | 房贷列负债，注明房产不纳入；报销待收列备忘。 | 称完整家庭净资产；把成本待补市值直接塞入平衡账表；费用已保留又累加同笔报销应收。 |
| 范围净额桥接 | 有完整同范围数据时，范围净额＝3001＋累计 3002＋累计收支结余＋累计 4003 未实现变化；3001／3002 按贷方净额计。累计结余为计算行。 | 以结余加单列未实现变化解释业务形成的净额变动，再衔接期初及范围加入／退出。 | 用系统科目补差；每月再生成一笔“结余收入”。 |

| 生活预算占用 living_budget | 按预算行的消费发生、特定事项履约或年度额度规则归集；普通信用消费在购买时占用，之后还款不再扣；按期付款事项以本金加利息合计占用。 | 生活额度包括房贷和既有分期付款，年度月分配只是计划；用途分组不改科目。 | 将所有还款都再次计费用；融资原购买与按期付款双扣生活额度；把预留当实际付款。 |

现金表按消费及工作垫付付款、工资、报销回款、家庭赞助、信用还款、退款提回、其他往来、投资申赎与分红、借款收付及本息、公积金提取等业务类型显示；不要求生活／投资／筹资三分法或普通还款原用途分配。报销垫付与回款保留真实日期，单列先垫后收资金占用；押金按往来显示，本人现金账户互转合并后抵销。本息未拆或性质未知但唯一现金事实明确的收付，分别显示为“本息待拆付款”或“未解释现金变动”，不因未生成完整凭证被排除。来源记录与已记账事实以同一事实 ID 去重，补齐分类后不新增现金；跨来源疑似重复未解决时保留缺口。现金展示不生成虚构平衡分录，也不意味着损益或债务已核对。未来安排与历史实际分栏，预测不计入实际期末余额；R/m 不当作固定月度回款，未知尾款、跨年待收和延迟风险明确披露。

预算参考窗口优先完整年度或滚动 12 个月，收入、费用和 R 使用同一窗口。确认完整但零回款的月份计入 m，缺月或部分月不得当零；资料不足时注明所选完整窗口或估计假设，不作无说明年化。报销抵减只在汇总行出现，不能改变 37 科目、逐笔实际及类别总额；若跨期错位导致标准化金额异常，保留计算并说明限制，不以虚构分类消除。预实分别展示原始与标准化结果，并解释费用变化、回款时点及估计变化；预算采用后冻结估计，修订另存版本。具体预算合同见主规格第 12 节。

生活预算以净工资作为资金来源时，已由该工资扣缴且有证据关联的税、社保及公积金不二次占额度；收支表仍保留真实费用与薪酬。另行发生的未含于净工资的税费等照常计入生活占用，不能对整个科目排除。年度项目按全年余额评价，月度安排与发生差额不当日常可花余额。详见主规格第 12.6 节。

每个统计结果附日期、账户范围、数据版本、完整性状态及待处理数量／金额；净额和消费都不能因页面显示一个总数就省略覆盖限制。

## 5. 从旧范围迁移

本节规定迁移方法，不使用旧金额，也不代表已执行迁移。先保留旧目录及视图版本，再明确切换日期、范围和映射；同一事实只在选定版本中计算一次。

| 旧设计 | v0.3 处理 |
|---|---|
| 工作垫付及退款已从费用剔除、回款核销报销应收 | 根据原事实恢复费用及真实退款冲减，回款恢复至 4005／报销回款；移除同笔旧 1004 资产效果，只保留备忘关联。先核对哪些效果已存在，禁止重复恢复、重复扣报销或用 3002 掩盖政策重算。原始文件不改，旧导出保留版本，新结果注明政策及重算范围。 |
| 报销与家庭赞助合并在其他收入或预算抵减 | 4005 分别标为报销回款、家庭赞助；只将报销回款纳入 R。家庭赞助不抵费用，未来默认不依赖；旧预算冻结保留，采用新估计另存版本。 |
| 按银行、卡片、商户建科目 | 合并到稳定叶子，原名称迁入账户、商户或产品维度；保留旧编码到新编码映射。 |
| 餐饮日用、居住、利息手续费等合并费用 | 根据已有用途证据映射至新类别；消费性质已明确但无法细分的进入 5016，不猜分摊比例。 |
| 房产、汽车、长期耐用品与累计折旧 | 房产、汽车及耐用品账面资产退出一期范围；不再产生折旧。若迁移已记账余额，只有明确范围退出及账面依据才可经 3002 移出；旧版历史不抹除。不能把旧资产余额一次性转成当期消费。 |
| 普通商品和订阅的预付／摊销 | 在覆盖的交易历史内，按有证据的购买事实重建消费，停用后续摊销并重算，避免购买和摊销重复计费；资料不足不凭余额编造购买日期。真正未履约预付保留待处理。 |
| 房贷和其他借款合并 | 按合同及本金依据拆为 2003／2004；缺本息资料继续待补。 |
| 期初净资产、直接调整、累计／当期结余科目 | 有证据的范围期初映射 3001，明确加入退出映射 3002；旧直接调整逐笔核验，不批量当范围变更。结余改为计算行，不搬成额外收入。 |
| 必须先冲销、月结后重开 | 当前交易直接编辑并留变更历史，按依赖重算当前有效视图；旧凭证及月结快照作为历史版本可追溯，不再要求日常强制结账。 |
| 已有投资市值但缺成本 | 保存持仓快照及缺失状态，不将市值重命名为成本，不初始化虚构估值收益。 |

实施校验：编码唯一；叶子数为资产 9、负债 5、系统范围净额 2、收入 5、费用 16，合计 **37**，1004 保留但本模式停用；禁止一般分类接口写入 3001／3002；未知资金性质不得通过 5016 入账；工作垫付已计费用时不得生成同笔应收资产；报销抵减不改变实际及类别金额，收入费用同时抵 R 后结余不变；同一投资持仓不得在快照展示层和正式账面重复累计；修改交易后相关消费、余额、成本及报表版本同步更新。
